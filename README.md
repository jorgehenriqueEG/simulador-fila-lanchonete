# Simulador de Fila de Lanchonete
## Descrição do Problema
Simular o tempo de espera de clientes em uma lanchonete com 2 atendentes.
## Requisitos
- Listas para ordenar por hora de chegada
- Regra de negócio: cada atendente serve um cliente por vez em ordem de chegada
- Calcular o tempo total de espera
## Exemplo de Uso
Entrada: clientes = [("Ana", 0), ("Beto", 5), ("Carla", 10)]
Saída: Tempo total de espera: 10 minutos
